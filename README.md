# Netflix Clone – HTML & CSS

A responsive Netflix-inspired landing page built using HTML and CSS as part of my frontend development practice.

## 🚀 Features

* Netflix-inspired landing page
* Responsive navigation bar
* Hero section with background image
* Email signup sections
* Feature sections
* FAQ accordion using HTML and CSS
* Responsive design for mobile screens
* Footer with navigation links
* CSS media queries for responsive layouts

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries
* Responsive Web Design

## 🎯 Purpose

This project was created to practice frontend development concepts including:

* HTML semantic structure
* CSS styling
* Flexbox layouts
* Responsive design
* Media queries
* Background images
* CSS-based FAQ accordion
* Form styling

## 📱 Responsive Design

The website includes CSS media queries to adapt the layout for smaller screen sizes such as mobile devices.
